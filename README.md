## 📖 Deskripsi

Repository ini digunakan untuk menyimpan seluruh hasil praktikum Jaringan Komputer yang saya kerjakan selama perkuliahan di **Telkom University**.

Isi repository meliputi:

* 📄 Laporan praktikum dalam format Markdown
* 🖼️ Screenshot hasil konfigurasi dan pengujian
* 🐍 Source code Python 
* 📚 Catatan dan dokumentasi tambahan
